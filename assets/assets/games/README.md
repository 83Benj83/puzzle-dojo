# Images des jeux — Puzzle Dojo

Dépose ici une image PNG par jeu pour remplacer l'illustration vectorielle
sur les cartes de l'accueil et l'en-tête de détail.

## Nom des fichiers (exactement)
- sudoku.png
- tectonic.png
- kakuro.png
- nonogram.png
- hitori.png
- futoshiki.png
- hashi.png
- nurikabe.png
- slitherlink.png
- shikaku.png

## Conseils
- Format carré recommandé (ex. 512x512), fond transparent ou coloré.
- Si un fichier est présent, il est utilisé automatiquement ; sinon on garde
  le dessin vectoriel par défaut.
- Après avoir ajouté/retiré des images, relance `flutter pub get` puis rebuild.
